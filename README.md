## 📖 Overview

The **Green GLO Cleaning Co** website is a fully responsive, modern marketing and booking platform for a premium eco-friendly cleaning company operating across Greater London. It features an instant price calculator, multi-step booking form with Formspree integration, detailed service listings, and a dedicated membership page (GreenGlo Club).

This project is designed to be **lightweight, fast, and easy to deploy** — no build tools, no frameworks, no dependencies beyond CDN-hosted Tailwind CSS and Font Awesome.
