## 📖 Overview

The **Green GLO Cleaning Co** website is a fully responsive, modern marketing and booking platform for a premium eco-friendly cleaning company operating across Greater London. It features an instant price calculator, multi-step booking form with Formspree integration, detailed service listings, and a dedicated membership page (GreenGlo Club).

This project is designed to be **lightweight, fast, and easy to deploy** — no build tools, no frameworks, no dependencies beyond CDN-hosted Tailwind CSS and Font Awesome.

---

## ✨ Features

### 🏠 Home Page (`index.html`)
- **Hero section** with looping video background and instant price calculator
- **Service tab switcher** (Domestic, End of Tenancy, Deep, Commercial)
- **Live cost estimator** based on bedrooms, bathrooms, frequency, and date
- **Trust strip** with BICSc certification, Google rating, insurance, and eco credentials
- **6 detailed service cards** with images, pricing, and CTAs
- **GreenGlo Club teaser** section with member rate comparison
- **"How it works"** 3-step process
- **Testimonials** from verified London clients
- **FAQ accordion** with 4 common questions
- **Multi-step booking form** (Formspree-ready) collecting:
  - Service type & property category
  - Contact details & postcode
  - Bedrooms, bathrooms, living areas, kitchens
  - Access method, parking, product/equipment sourcing
  - Specialized add-ons (windows, carpet, oven, upholstery, biohazard)
  - ULEZ / Congestion Zone status
  - Preferred date, frequency, service window, and notes
- **Floating mobile CTAs** (Call + WhatsApp)

### 🌿 GreenGlo Club Page (`club.html`)
- Membership landing page with 20% savings messaging
- Member snapshot card showing rate comparison
- **Benefits grid** — priority scheduling, dedicated cleaner, free re-clean, add-on discounts
- **Comparison table** showing annual savings breakdown
- **3-step activation** explainer
- **Formspree membership signup form** with frequency and preferred day
- Member testimonials
- Club-specific FAQ accordion
- Full CTA section

### 🎨 Design System
- **Brand colours:** Sage green palette (`sage-50` → `sage-950`) + mint accents
- **Typography:** Plus Jakarta Sans (300–800 weights)
- **Glassmorphism** cards with backdrop blur
- **Soft cloud cards** with layered shadows
- **Floating orb** ambient animations
- **Custom scrollbar** styling
- Fully **mobile responsive** with hamburger menu and sticky header
